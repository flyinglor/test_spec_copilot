- [ ] 3 experience entries render in timeline order (most recent first)
- [ ] Each entry shows: date range (e.g. "Jan 2022 – Present"), org name, role, description, skill tags
- [ ] "Present" label shown for current roles (`endDate: null`)
- [ ] Organisation name styled in accent colour

## Education section

- [ ] 1 education entry renders below experience
- [ ] Same layout/style as experience entries

## Skills section

- [ ] 4 skill groups render in auto-fill grid (Languages, Frameworks, Infrastructure, Data)
- [ ] Each card shows label + list of items

## Responsive
